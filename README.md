# weta-technologies.github.io

The source of [weta-technologies.github.io](https://weta-technologies.github.io/) — the downloads hub for the apps
Weta Technologies publishes on GitHub. Static HTML and one stylesheet, no build step, no JavaScript.

| Page | What it is |
| --- | --- |
| `/` | Landing page: one tile per platform. To add a platform, copy one `<a class="tile">` block in `index.html`. |
| `/mac-apps/` | One card per Mac app with its Download button. The download links are kept together at the top of that page's `<section>` — see the `RELEASE:` comment there when an asset name changes. |
| `/404.html` | Not-found page. |

Fonts (Nunito, Inter, Plus Jakarta Sans) are self-hosted under the SIL Open Font Licence — see `assets/fonts/LICENSE.md`.
